# Diet Design

다이어트 디자인 코칭 앱. 종이 주간 기록지(수면·체중·허리·화장실·생리 + 하루 타임라인)를 그대로 옮긴 웹앱으로 시작해, 이후 모바일 앱으로 확장한다.

## 구조

```
apps/web        Next.js 웹앱 (PWA 예정)
packages/core   화면과 무관한 공용 로직 — 타입, 수면량·D-day·타임라인 계산, 저장소 인터페이스
                (나중에 React Native 앱에서도 그대로 재사용)
supabase/       DB 스키마와 접근 권한(RLS)
```

## 실행

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm test         # 공용 로직 테스트
pnpm lint && pnpm typecheck
```

## 진행 상황

- [x] **1단계 — 기록하기**: 아침 체크(수면량 자동 계산, 생리 D-7~D+7 자동 표시), 식사 기록(시각·음식과 양·포만감·사진), 하루 타임라인, 주간 보기(종이 기록지 형태), 코치에게 보내기
  - 지금은 체험판: 기록은 브라우저(IndexedDB)에만 저장된다
- [x] **매일 쓰기 편하게**
  - 사진부터 기록 → 촬영 시각(EXIF)을 먹은 시각으로 자동 입력, 방금/30분 전/1시간 전 버튼
  - 자주 먹는 음식 버튼, 최근 식사 그대로 다시 기록
  - 누구와 먹었는지(가족·친구·동료/회식) + 나눠 먹었을 때 내가 먹은 양
  - 타임라인 윗줄(수면 줄)을 눌러 일어난·잠든 시각 기록 (오후 2시 기준), 다시 누르면 이동, ✕로 지우기
  - 체중·허리는 지난 기록에서 ±0.1 조정
  - 다음 날 오전 9시 자동 보내기, 보낸 뒤 고치면 "수정됨" 표시, 빠진 끼니 "안 먹었어요" 확인
  - 타임라인 빈 곳을 누르면 그 시각으로 바로 기록, 끼니 버튼(아침·점심·간식·저녁·야식)
  - 새 식사에 지난번 비슷한 시각에 먹은 것을 수정 가능한 예시로 채움
  - 사진 여러 장을 촬영 시각별 식사로 자동 분리, 시각 정보 없는 사진은 시각을 묻기
  - "한 번에 쓰기": 종이처럼 `9:00 과채스무디` 여러 줄로 하루치 기록 (포만 8 인식)
  - 생리 기록 사용 끄기
  - 홈 화면 설치(PWA 매니페스트·아이콘)
