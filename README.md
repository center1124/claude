# Diet Design

다이어트 디자인 코칭 앱. 종이 주간 기록지(수면·체중·허리·화장실·생리 + 하루 타임라인)를 그대로 옮긴 웹앱으로 시작해, 이후 모바일 앱으로 확장한다.

## 구조

```
apps/web        Next.js 웹앱 (PWA 예정)
packages/core   화면과 무관한 공용 로직 — 타입, 수면량·D-day·타임라인 계산, 저장소 인터페이스
                (나중에 React Native 앱에서도 그대로 재사용)
supabase/       DB 스키마와 접근 권한(RLS)
```

## 실행

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm test         # 공용 로직 테스트
pnpm lint && pnpm typecheck
```

## 진행 상황

- [x] **1단계 — 기록하기**: 아침 체크(수면량 자동 계산, 생리 D-7~D+7 자동 표시), 식사 기록(시각·음식과 양·포만감·사진), 하루 타임라인, 주간 보기(종이 기록지 형태), 코치에게 보내기
  - 지금은 체험판: 기록은 브라우저(IndexedDB)에만 저장된다
- [x] **매일 쓰기 편하게** (입력은 하루 기록, 보기는 주간 보기)
  - 아침 체크: 수면(어젯밤 잠든 → 오늘 일어난, "지난번과 같게" 한 번에), 체중·허리(지난 기록 ±0.1), 화장실, 생리(D-7~D+7, 끌 수 있음)
  - 식사: 사진부터 기록(촬영 시각 자동, 시각 없는 사진은 묻기, 여러 장은 식사별로 나눔),
    끼니 버튼(아침·점심·간식·저녁·야식), 지난번 비슷한 시각 식사를 수정 가능한 예시로,
    자주 먹는 음식 버튼
  - 🎤 말로 한 번에 기록: 키보드 받아쓰기로 하루를 말하면 수면·체중·허리·화장실·식사·운동을 칸별로 나눠
    확인 후 저장 (AI 없이 규칙으로 읽음, 알아듣지 못한 말은 따로 표시. core: parseSpokenLog)
  - 운동: 내 운동 루틴(설정)을 체크 목록으로, "어제와 같아요"·"오늘은 쉬었어요" 한 번, 양은 ±버튼
    (시간 10분·세트 1·거리 0.5km·걸음 1,000), 운동한 때(아침·점심·저녁) 선택,
    "+ 다른 운동"은 최근 2주 안에 한 것 중 최대 5개만
  - 하루 흐름 그림(보기용), 다음 날 오전 9시 자동 보내기, 보낸 뒤 고치면 "수정됨", 빠진 끼니 "안 먹었어요"
  - 홈 화면 설치(PWA)
- [x] **주간 보기**: 한 주 요약(평균 수면·기상·취침, 첫/마지막 식사, 하루 식사, 야식, 포만감, 운동한 날·시간, 체중·허리)과 지난주 비교.
  폰은 요일마다 한 줄 흐름 그림 + 지난주 겹쳐 보기 + 요일 누르면 그날 기록, PC는 종이 주간 기록지 모양
- [ ] Supabase 연결: 로그인(카카오), 서버 저장, 사진 업로드 — 스키마는 `supabase/migrations/0001_init.sql`
